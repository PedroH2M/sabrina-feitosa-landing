# Sabrina Feitosa — Studio Criativo

Landing page editorial **mobile-first** desenvolvida para **Sabrina Feitosa** (**Videomaker, Social Media & Branding**), com atendimento presencial em João Pessoa - PB e remoto para todo o Brasil.

## Identidade Visual (Regra 60-30-10)

- **60% Creme:** `#FAF5EC` / `#F1E7D6`
- **30% Marrom Espresso:** `#361F13` / `#24130B`
- **10% Mostarda:** `#D49B27` / `#E4AF3C`

## Stack

- **Vite + React 19 + TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Motion** (`motion/react`) + **Lenis** (scroll suave respeitando `prefers-reduced-motion`)
- **Lucide React** (ícones)

## Como executar localmente

```bash
npm install
npm run dev
```

## Scripts disponíveis

- `npm run dev` — inicia o servidor de desenvolvimento local
- `npm run lint` — executa verificação estática com `oxlint`
- `npm run build` — valida tipagem (`tsc -b`) e gera o bundle de produção em `dist/`
- `npm run preview` — pré-visualiza o build de produção localmente
